# Pertanyaan yang Sering Diajukan (FAQ)

*Kuron Desktop (Windows, macOS, Linux).*

---

**Q: Apa itu Kuron?**

Kuron adalah klien pihak ketiga tidak resmi untuk menjelajahi konten. Kuron Desktop adalah port versi mobile (Flutter Android) ke komputer dengan antarmuka desktop, dibangun dengan Tauri v2 + Rust + Svelte.

---

**Q: Apakah Kuron gratis?**

Ya, Kuron sepenuhnya gratis dan open-source. Anda dapat melihat kode sumbernya di GitHub (`shirokun20/kuron-desktop-tauri-version`).

---

**Q: Apakah Kuron aman digunakan?**

Ya. Aplikasi tidak mengumpulkan data pribadi apapun dan semua informasi disimpan secara lokal di komputer Anda.

---

**Q: Di mana file unduhan disimpan?**

Unduhan disimpan di folder data aplikasi di komputer Anda dan dapat dibaca tanpa koneksi internet.

---

**Q: Bisakah saya menggunakan aplikasi secara offline?**

Ya! Konten yang telah Anda unduh dapat diakses tanpa koneksi internet.

---

**Q: Bagaimana cara menambahkan konten ke favorit?**

Buka galeri manapun dan gunakan tombol favorit untuk menambahkannya ke daftar favorit Anda.

---

**Q: Bagaimana cara menghapus riwayat baca?**

Riwayat dapat dihapus dari dalam aplikasi. Untuk menghapus seluruh data, uninstall aplikasi.

---

**Q: Aplikasi tidak bisa terhubung / menampilkan error**

Coba solusi ini:
1. Periksa koneksi internet Anda
2. Website sumber mungkin sedang down sementara
3. Coba gunakan VPN jika akses diblokir di wilayah Anda
4. Muat ulang halaman
5. Coba ganti sumber konten dari sidebar

---

**Q: Gambar tidak dimuat**

1. Periksa koneksi internet Anda
2. Muat ulang halaman atau buka ulang detail konten
3. Bersihkan cache aplikasi
4. Server sumber mungkin mengalami traffic tinggi

---

**Q: Unduhan gagal**

1. Pastikan Anda memiliki ruang penyimpanan yang cukup
2. Pastikan aplikasi punya akses tulis ke folder tujuan
3. Coba unduh lebih sedikit item sekaligus
4. Periksa stabilitas internet Anda

---

**Q: Aplikasi lambat atau lag**

1. Hapus unduhan yang sudah selesai
2. Hapus riwayat baca yang lama
3. Restart aplikasi

---

**Q: Apakah aplikasi mengumpulkan data saya?**

Tidak. Kuron tidak mengumpulkan informasi pribadi apapun. Semua data (riwayat, favorit, pengaturan) disimpan secara lokal di komputer Anda saja.

---

**Q: Apakah riwayat browsing saya dibagikan?**

Tidak. Riwayat browsing Anda tidak pernah dibagikan dan tetap hanya ada di komputer Anda.

---

**Q: Bagaimana cara menghapus semua data saya?**

Anda bisa:
- Hapus riwayat, favorit, dan unduhan dari dalam aplikasi
- Uninstall aplikasi (menghapus semua data)

---

**Q: Bagaimana cara memperbarui aplikasi?**

Buka **Tentang → Pembaruan Aplikasi**. Anda akan diberi tahu ketika versi baru tersedia di GitHub.

---

**Q: Mengapa aplikasi tidak ada di toko aplikasi (App Store / Microsoft Store)?**

Karena pembatasan konten, aplikasi didistribusikan hanya melalui GitHub releases.

---

**Q: Bagaimana cara melaporkan bug?**

Silakan buka issue di repositori GitHub kami dengan:
- Deskripsi masalah
- Langkah-langkah untuk mereproduksi
- Sistem operasi dan versi Anda (Windows / macOS / Linux)

---

**Q: Bagaimana saya bisa berkontribusi?**

Aplikasi ini open-source! Anda dapat berkontribusi dengan:
- Mengirimkan laporan bug
- Menyarankan fitur
- Berkontribusi kode melalui pull request
