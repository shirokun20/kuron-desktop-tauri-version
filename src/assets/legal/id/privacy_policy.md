# Kebijakan Privasi

**Terakhir Diperbarui: Januari 2026**

*Berlaku untuk Kuron Desktop (Windows, macOS, Linux).*

## Ringkasan

Kuron Desktop ("Aplikasi") berkomitmen untuk melindungi privasi Anda. Kebijakan Privasi ini menjelaskan bagaimana kami menangani informasi Anda saat menggunakan Aplikasi kami.

## Pengumpulan Data

### Apa yang TIDAK Kami Kumpulkan

✅ **Tidak ada informasi pribadi** - Kami tidak mengumpulkan nama, email, atau informasi identitas apapun

✅ **Tidak ada sistem akun** - Tidak perlu login atau registrasi

✅ **Tidak ada pelacakan eksternal** - Tidak ada layanan analitik atau pelacakan pihak ketiga

✅ **Tidak ada penyimpanan server** - Kami tidak mengoperasikan server backend yang menyimpan data Anda

### Apa yang Disimpan Secara Lokal

Data berikut disimpan **hanya di komputer Anda**:

| Jenis Data | Tujuan | Lokasi |
|------------|--------|--------|
| Riwayat Baca | Melacak apa yang telah Anda baca | Database SQLite lokal |
| Favorit | Menyimpan galeri favorit Anda | Database SQLite lokal |
| Unduhan | Membaca offline | Folder data aplikasi |
| Pengaturan | Preferensi Anda (tema, sumber) | Penyimpanan lokal aplikasi |
| Riwayat Pencarian | Akses cepat ke pencarian sebelumnya | Penyimpanan lokal |

## Berbagi Data

**Kami tidak membagikan data apapun kepada pihak ketiga.**

- Tidak ada data yang dikirim ke server kami (kami tidak punya)
- Tidak ada jaringan iklan
- Tidak ada platform analitik
- Tidak ada integrasi media sosial

## Koneksi Jaringan

Aplikasi terhubung ke:

- **Sumber konten** (NHentai, Hitomi, E-Hentai, MangaDex) - Untuk mengambil konten dan gambar
- **GitHub API** - Hanya untuk memeriksa pembaruan aplikasi (saat Anda menekan Periksa Pembaruan)
- **Tidak ada koneksi lain**

## Keamanan Data

- Semua data tetap di komputer Anda
- Tidak ada sinkronisasi cloud atau backup ke server eksternal
- Data seaman komputer Anda

## Penghapusan Data

Anda memiliki kontrol penuh atas data Anda:

- **Hapus Riwayat / Favorit / Unduhan**: dari menu masing-masing di aplikasi
- **Reset Pengaturan**: hapus penyimpanan lokal aplikasi
- **Penghapusan Lengkap**: uninstall Aplikasi (menghapus semua data)

## Privasi Anak-Anak

Aplikasi ini **tidak ditujukan untuk pengguna di bawah 18 tahun**. Kami tidak dengan sengaja mengumpulkan informasi dari anak di bawah umur.

## Perubahan Kebijakan Ini

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu. Perubahan akan tercermin pada tanggal "Terakhir Diperbarui" di atas.
